## Executed evidence

- 67 Playwright journeys pass, including actual playback of WAV, MP3, M4A, FLAC and OGG fixtures in Chromium, delayed-save navigation, managed-draft and batch recovery, note review, bulk speakers and actual export preview.
- The synthetic four-hour/6,000-turn fixture renders bounded pages. An isolated 12-edit run measured 26 ms p95 edit-to-two-animation-frames latency. This excludes native IPC/disk latency and multi-hour audio inference.
- 111 Rust tests pass, including fallback language selection and runtime dependency invalidation.
- Frontend build, lint and strict translation checks pass. Seven worker and four draft/save-queue/progress tests pass; five evaluation-scorer tests cover overlap, timestamp limits and factual-support review.
- Packaged Qwen ASR/aligner, Qwen3.5-9B and Qwen3.6-27B notes have run with networking denied. The 27B smoke completed in 16.84 seconds, reported 7.77 GB process peak RSS and 15.79 GB MLX peak allocation on this 48 GiB Apple Silicon machine. Unified-memory counters must not be added. This tiny English fixture is not a quality or memory-bound benchmark.
- The Developer ID macOS app builds and passes outer strict signature verification. Both embedded workers pass nested signature/hash checks and offline dependency startup. Notarization remains pending; see runtime status for all verification results.

## Open release gates

1. Publish Community-1's complete offline bundle and attribution manifest on the owner's download server, then verify loading, global speaker identities and overlap end to end.
2. Evaluate exact shipped artifacts against annotated meetings: accents, mixed languages, silence, overlap, multi-hour recordings, timestamp accuracy and human-reviewed notes. Compare quantization and acceleration against reference outputs.
3. Run capture fault scenarios on actual hardware and validate all codecs in WKWebView. Unit and browser fixtures cannot certify these behaviors.
4. Complete signed/notarized package checks and clean-machine operation with networking blocked; verify preserved Intel, Windows and Linux functionality.
5. Close the remaining software/acceptance items in the table. The full plan is still active; this checkout is not being represented as release-ready.

Import preflight now exercises only the selected premium runtimes before audio copying. It reserves import ownership through the dependency check and honors cancellation before copying. Failed capture finalization preserves duration and updates tray state; recovery flushes its repaired file before replacement and preserves an existing destination on invalid source samples.

Home now surfaces a separate Needs attention group for failed/interrupted jobs and completed transcripts with optional-stage failures. It uses a dedicated Library query and filter, so recovery work does not depend on the recent-transcript page. Cancelled jobs remain available in Library without automatically demanding attention. Backend filter coverage and the Home-to-filtered-Library journey pass.

Settings now has six primary workflow groups. Advanced output/transcription and experimental controls are embedded under Dictation; startup/overlay under Appearance; runtime acceleration/unloading under Models & language; and support under Storage & privacy. Processing/debug panels remain conditional disclosures. The 65-journey suite and a new six-group navigation test pass.

Note items now retain source text, real nullable timing and capture revision independently of transcript corrections. Section replacements retain their own source versions; Markdown footnotes and JSON resolve distinct versions of the same segment. Legacy notes without historical excerpts do not claim unavailable provenance. Rust coverage rejects altered excerpts and verifies mixed-revision export; a browser journey verifies old evidence alongside a corrected transcript. The 67-journey suite, 110 Rust tests, build, lint and translation checks pass.

The [manual end-to-end checklist](manual-end-to-end-checklist.md) is a working handoff draft, not a completion claim. Community-1 now has a packaged offline diarization smoke command; cached smoke artifacts are hash-checked even without downloads, and unpublished packs are rejected. Two smoke preparation tests pass. The actual Community-1 pipeline remains unverified pending its published bundle.

The 15 September signed debug app was rebuilt with consolidated Settings, Home attention items and saved note evidence. Strict outer signature verification passes; embedded speech (545 signatures / 7,088 records) and notes (89 signatures / 3,567 records) pass hash/signature verification and network-denied dependency startup. This build remains unnotarized. Latest executed checks: 110 Rust tests, 67 browser journeys, four frontend units, seven worker tests, seven artifact verification tests and two smoke preparation tests pass. The separately documented command-runner test failures are not represented as resolved.

Processing progress now uses protocol version 2 and a durable per-attempt ID, separate from transcript revision. Each processing start records a fresh identity and resets progress; late updates from earlier attempts are rejected even when stage and transcript revision match. Older records default to an empty identity and remain readable. The storage/restart regression and four progress/save-queue units pass; the full Rust suite has 111 passing tests and 67 browser journeys pass. Frontend build and lint pass. The most recent signed app predates this attempt-ID change and must be rebuilt before final release acceptance.
